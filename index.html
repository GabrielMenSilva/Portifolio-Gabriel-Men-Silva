Projetos e Certificados

Fitcore

O FitCore é uma aplicação desenvolvida em Python para auxiliar no acompanhamento de saúde e desempenho físico. O sistema realiza cálculos de IMC, hidratação diária, gasto calórico e Taxa Metabólica Basal (TMB). Também permite definir objetivos como emagrecimento, manutenção de peso e ganho de massa muscular.

Puc Eats

O Puc Eats é um protótipo de delivery universitário desenvolvido para conectar estudantes a restaurantes próximos ao campus da PUCPR. O projeto conta com login, cadastro, cardápio, busca, filtros e notificações de promoções. Foi desenvolvido utilizando HTML5, CSS3 e JavaScript, com foco em experiência do usuário e interatividade. A aplicação demonstra a prática de desenvolvimento web e a criação de uma solução voltada às necessidades do ambiente universitário.

RPG em Java

Um sistema de RPG em Java usando Programação Orientada a Objetos. O jogador cria um personagem (nome, classe e vida máxima) via terminal com Scanner, podendo editar os atributos depois através dos métodos get e set da classe Personagem.
