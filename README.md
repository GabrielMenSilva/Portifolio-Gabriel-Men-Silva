Gabriel Men Silva — Portfólio

Site pessoal desenvolvido com HTML, CSS e JavaScript puro, apresentando minha trajetória como desenvolvedor Full-Stack, minhas habilidades técnicas e os projetos e certificações que já produzi.

🔗 Preview: abra index.html no navegador (ou rode com o Live Server do VS Code).

📖 Sobre

Sou estudante de Sistemas de Informação na PUC-PR e desenvolvedor em formação, com foco em desenvolvimento web e soluções Full-Stack. Este portfólio reúne meus principais projetos, habilidades e formas de contato.

HTML5 — estrutura semântica das seções
CSS3 — layout responsivo, flexbox, transições e animações
JavaScript — interatividade dos cards de projetos (expandir/recolher)
Google Fonts — Inter, Open Sans e Roboto

Layout responsivo — adaptado para desktop, tablet e celular
Formulário de contato com campos validados (nome, e-mail, telefone e mensagem)

🚀 Como rodar localmente
Baixe ou clone os arquivos deste projeto
Abra a pasta no VS Code
Instale a extensão Live Server (se ainda não tiver)
Clique com o botão direito em index.html → Open with Live Server

Ou simplesmente abra o arquivo index.html diretamente no navegador.
